# SWZA — event operations lessons

Status: HISTORICAL lessons / PROPOSED controls. Evidence: extracted/Data Exports/02_Discord_Analyza_10_06_2026_opakovane_problemy_a_riesenia.md, supported by 01 annual timeline, 03 checklists, 04 roles and 06 sponsor/grant analysis in the same directory. Current task/owner/deadline comes from the selected edition's live records.

| Historical failure | Reusable control for AI Zuzka | Verify before action |
|---|---|---|
| Dietary information collected but not used | Prepare a catering brief from current registration data | Count/diet scope and responsible catering person; restricted details stay internal |
| Shopping list appears too late | Consolidate needs with an owner and a cutoff tied to the confirmed event | Current quantities, purchasing approval and physical collection |
| Sponsor logos arrive late and block graphics | Track each missing logo and its dependent asset | Current partner agreement, logo rights and designer handoff |
| Venue decision blocks registration/graphics | Make prerequisites visible and escalate a stalled decision | Actual reservation/status and the human decision owner |
| Timer screens / AV forgotten | Add equipment and on-site verification to the event brief | Human confirms actual devices and test result |
| Mentor identity / entry confusion | Prepare current mentor roster and check-in brief | Current approved roster; no historical contact auto-invite |
| Parent/companion catering confusion | Draft explicit edition-specific participant information | Current ticket terms and event policy, not old pricing |
| Cleanup has no capacity/owner | Assign human shift/backup and completion evidence | Availability and actual physical completion |
| Winners do not use prizes | Prepare bounded follow-up tied to each agreed prize | Current eligibility, expiry and partner obligation |
| Grant reporting/application missed | Track the actual call/reporting obligation and evidence | Fresh official deadline and responsible human |
| Website/domain outage unnoticed | Check existing monitoring/renewal ownership | Live coverage and permissions before proposing new tooling |
| Last-minute program changes | Publish one approved run-of-show and stop obsolete reminders | Approved latest schedule and affected recipients |

Annual calendar: historical January–October/month-specific examples are planning evidence. Derive a new plan only after its edition/date is confirmed; use event-relative offsets where appropriate. Grant calls and contractual obligations need their own fresh dates.

Post-event is part of the job: delivery/prizes, partner thank-yous, grant/accounting evidence, participant follow-up and lessons for the next cycle. No suggested control above is a claim that a workflow is already deployed.
